# Capturas — Filmes HD Online Grátis

Capturas da interface publicada em https://filmeshdonlinegratis.vercel.app/, usadas como mídia do case, do grid, do Sobre
e da imagem de compartilhamento (via `scripts/brand/build-brand-assets.mjs`, tarefa `cases` e `atlas`).

- Data: 16/11/2026.
- Navegador: Google Chrome (Playwright, sem interface), idioma pt-BR, densidade 2×.
- Tamanhos: `d-*` em 1440×900 (arquivo 2880×1800); `m-*` em 390×844 (arquivo 780×1688).
- Navegação apenas com GET; os únicos cliques foram os controles de interface "Entrar" (abertura) e "Fechar" (dica de
  navegação). Nenhum formulário enviado, nenhum cookie aceito.
- `d-home` e `m-home` foram recapturadas em quadros em que o efeito de glitch do título não estava ativo.

| Arquivo | Conteúdo |
|---|---|
| `d-home`, `m-home` | página inicial com a sessão em destaque |
| `d-home-drag` | página inicial depois de arrastar o conteúdo |
| `d-programacao`, `m-programacao` | programação em modo de cenas |
| `d-sobre`, `m-sobre` | página Sobre |
| `d-sessao`, `m-sessao` | página de uma sessão (topo) |
| `d-sessao-18`, `m-sessao-18` | ficha técnica |
| `d-sessao-33` | elenco e galeria |
| `d-sessao-50`, `m-sessao-50` | leituras |
| `d-sessao-70`, `m-sessao-70` | ficha da sessão e bloco "Na sala" |
| `d-sessao-86`, `m-sessao-86` | rodapé com RSS, navegação e contato |

As imagens mostram cenas dos filmes da programação como parte da interface do site.
